// ============================================================
//  SETWORD.txt — Kata-kata Terminal & Loading Screen
//  Edit baris di bawah buat ganti teksnya. Baris yang diawali
//  // dianggap komentar (diabaikan).
//
//  Ada 2 jenis baris, pisahkan pakai tanda |
//
//  1) BOOT|teks
//     Baris log yang muncul di LOADING SCREEN pas web pertama
//     dibuka (sebelum isi web kelihatan).
//     Contoh: BOOT|Verifikasi lisensi... OK
//
//  2) CMD|perintah|hasil
//     Command yang diketik otomatis di kotak terminal kecil
//     di halaman utama, muter terus gantian.
//     Contoh: CMD|whoami|guest@cdaaptnia
//
//  Placeholder yang bisa dipakai di teks/hasil:
//   {produk}  -> otomatis diganti jumlah produk di data.js
//   {admin}   -> otomatis diganti jumlah admin kontak
// ============================================================
